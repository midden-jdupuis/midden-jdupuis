# John Dupuis

**AI Evaluation & Verification Engineer** · Cincinnati, OH

I build the part of AI-assisted software that tells you whether the code did what was meant.

Since January 2026 I have worked full time on **FROID**, a specification system precise enough
that a program can be regenerated from it by independent builders, human or model, and checked
against an oracle written before any of them start. The specification is written in itself.
Twelve years of infrastructure operations sit underneath that work.

## What I do

- **Specification systems.** Every component permanently addressed, every rule one checkable
  sentence, every cross-reference bidirectional.
- **Test oracles.** Authored before the first run, kept out of the builders' reach, graded
  mechanically.
- **Multi-model evaluation.** The same rule sheet handed cold to nine builders across three model
  tiers. Where they disagree, the rule is loose. Tighten it, run again. One tool converged to
  316 of 320 agreeing vectors, with every strong-tier builder at 40/40.
- **Language independence.** A Spanish translation of one rule sheet produced a program that passed
  the same oracle as the English one. A French human-translation arm is in progress.
